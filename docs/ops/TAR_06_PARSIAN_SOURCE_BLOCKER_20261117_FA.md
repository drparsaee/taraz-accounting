# سؤال باز برای تصمیم مالک

**کدام نسخه/کپی رسمی و قابل اتکای داده‌های پارسیان، شامل فهرست همهٔ سال‌های مالی و ماژول‌ها، مجاز است برای ممیزی فقط‌خواندنی روی Clone ایزوله استفاده شود؟**

این سؤال فقط برای تکمیل اثبات پوشش تمام داده‌هاست. **تا پاسخ و سند منشأ معتبر وجود نداشته باشد، وارد دادهٔ مالی واقعی نمی‌شویم** و هیچ Import یا سند افتتاحیهٔ واقعی انجام نمی‌دهیم.

## TAR-06 | بخش قابل انجام بدون دادهٔ واقعی

وضعیت: **PARTIAL SOURCE IMPLEMENTATION / DATA PROVENANCE BLOCKED**.

فایل `taraz_parsian_coverage.py` یک مدل خلاصه و کاملاً فقط‌خواندنی می‌سازد که:

- فهرست سال‌های «مورد انتظار» را **صریح و الزامی** می‌گیرد؛ هیچ سالی را از روی `1404` و `1405` فرض نمی‌کند.
- ماژول‌های اجباری (اشخاص، حساب‌ها، فاکتورها، ژورنال، تسویه و هر مورد دیگر) را با موجودی مشاهده‌شده مقایسه می‌کند.
- برای سال مفقود، ماژول مفقود، سال اضافه، نام تکراری، تعداد سطر نامعتبر، هش بدقالب و ارز غیرریالی نتیجهٔ محافظه‌کارانه می‌دهد.
- فیلدهای آزاد یا داده‌دار مانند نام مشتری، ردیف خام، مبلغ مانده و مسیر فایل را رد می‌کند؛ خروجی حاوی هیچ ردیف مالی نیست.
- حتی با پوشش ساختاری کامل، **همیشه** `readyForMigration: false`، `postingAllowed: false` و `sourceAuthenticated: false` برمی‌گرداند؛ از روی SHA-256 خوداظهاری ادعای اصالت نمی‌کند.

**شواهد:** `tests/test_taraz_parsian_coverage_20261117.py`، نتیجهٔ ۹/۹ PASS روی Manifest کاملاً ساختگی. هیچ دیتابیس، CSV، پروندهٔ واقعی یا دادهٔ نصب‌شده باز نشده است.

## چرا این Task هنوز پایان‌پذیر نیست؟

فهرست واقعی و کامل تمام سال‌ها/ماژول‌ها باید از **مرجع مورد تأیید** استخراج شود. گزارش‌های قبلی فقط دو آرشیو `1404` و `1405` و بخشی از صورتحساب‌ها را توصیف می‌کنند؛ از آن‌ها نمی‌توان نتیجه گرفت همهٔ سال‌ها و رکوردها پوشش داده شده‌اند. همچنین هش فایل بدون کنترل مستقل منشأ و سطح دسترسی، اثبات انتقال صحیح نیست.

**حرکت موازی ایمن:** تا تعیین منبع رسمی، TAR-06 در وضعیت `blocked` باقی می‌ماند و کار فعال به TAR-09 (قرارداد و آزمون مالیات خرید با دادهٔ مصنوعی) انتقال می‌یابد. TAR-07/TAR-08، Migration واقعی و انتشار همچنان وابسته و مسدودند.
